# Git Practice Repository (`gp`)

Welcome to my Git practice repository! This repo serves as a playground for learning, experimenting, and mastering Git and GitHub workflows.

## 🎯 Purpose

- Practice essential Git commands (`commit`, `branch`, `merge`, `rebase`, `checkout`, `stash`, etc.).
- Experiment with multi-branch workflows and resolving merge conflicts.
- Explore GitHub features like Pull Requests, Issues, Actions, and Markdown formatting.

## 🚀 Common Commands Quick Reference

### Basics
```bash
# Clone the repository
git clone [https://github.com/par-vezsiddiqui/gp.git](https://github.com/par-vezsiddiqui/gp.git)

# Check status
git status

# Stage changes
git add .

# Commit changes
git commit -m "Your commit message"

# Push to main
git push origin main
